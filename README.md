# ACL Tracker · 五大联赛前十字韧带伤病记录

ACL Tracker 从 2026–27 赛季的伤病名单起步，随后回补了 2025–26 和 2024–25 两个赛季。网站记录英超、西甲、德甲、意甲和法甲球员的前十字韧带（ACL）伤情。部分其他联赛球员也有记录，可通过「其他」查看。

[2026–27 赛季](https://lambertyan129.github.io/acl-tracker/) · [2025–26 赛季](https://lambertyan129.github.io/acl-tracker/2025-26/) · [2024–25 赛季](https://lambertyan129.github.io/acl-tracker/2024-25/)

## 怎么查看

- 点击页首的赛季名称切换赛季。可以搜索球员中文名、英文名或球队，也可以按联赛筛选。
- 点击任意一条球员记录，打开居中详情弹窗。里面有受伤经过、具体伤情、公告和报道，以及可查到的身高、体重和 FM 位置适应度。表格里的「查看公告」可直接打开原链接。
- 年龄按受伤时计算。伤情栏会区分左膝、右膝、侧别未公开与侧别报道不一。仍待核实的条目和后十字韧带（PCL）伤病在页面上有标注。FM 球场图只展示位置适应度，图上方标明数据版本。

## 维护资料

| 路径 | 用途 |
| --- | --- |
| `index.md`、`2025-26/index.md`、`2024-25/index.md` | 各赛季的名单、受伤位置和公告链接。 |
| `_data/` | 球员资料、伤病详情、身高体重、队徽映射和 FM 位置数据。历史赛季的详情按「日期 + 英文名」关联名单。 |
| `_layouts/acl.html`、`assets/acl/site.css`、`assets/acl/site.js` | 页面模板、样式、筛选和详情交互。 |
| `assets/acl/` | 本站使用的球员头像、队徽、联赛标志和国旗。 |

站点由 GitHub Pages 从 `main` 分支的仓库根目录构建。日常维护时，可用 GitHub Desktop 提交并推送本次改动的文件。
